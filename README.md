# Motion Strobe 1.17.4 · ストロボ合成・座標データ・運動のグラフ

ブラウザーで動画を一定の時間間隔で抽出してストロボ写真に合成します。各コマに記録された時刻を表示・運動解析に使います。サーバーへの動画アップロードは行いません。写真と、元動画に物体像を重ねたMP4（シャッター音は任意）を作成・保存・共有できます。

## 利用

1. 横並びの「動画を選ぶ」「動画を撮る」「サンプル動画で試す」から動画を用意する。「動画を撮るコツ」は初めから展開。
2. 開始・終了・背景を選ぶ。背景の初期値は開始の0.1秒前（動画開始で下限）。時間バーをピンチで拡大・縮小、ドラッグで移動、ダブルタップで全体表示。
3. 時間間隔を整数コマ分で指定し、基準を選ぶ。初期間隔0.1秒。基準の画像は必ず残り、端点を追加しない。
4. 写真を合成。感度初期値30、任意の時刻・縦横線の表示、PNG保存・共有。間隔を選び直すときは上の「2」へ戻る。
5. 「位置を検出」で物体をタップ。「全コマを自動検出」で指定を起点に追跡できる。コマごとに「自動」「手動」「なし」を選び、「なし」は線と時刻を省略。「座標データ」でx,yを確認・コピー・CSV保存。長さ・軸を校正するとm座標を別列に追加する。
6. 画像上の「動画」タブでMP4を作成・確認。動画を保存・共有。
7. 「グラフ」でy–x、x–t、y–tを表示。未校正はpx、校正後はm。各グラフに0〜3次の多項式またはsin（正弦波）をフィットでき、曲線と式を確認する。各軸を独立に拡大縮小でき、縦横比は固定しない。同じx・y・t軸の範囲はグラフ間で連動する。

初期設定だけを、この端末のブラウザー内に保存します。オープニングには用意したGIFアニメーションを表示します。作成した写真で上書きしません。範囲選択画面では基準を表示せず、時間間隔画面で操作します。処理の進捗・キャンセルに対応しています。

## 対応と制限

- HTTPSで配信。WebCodecs VideoDecoder、OffscreenCanvas（worker）、module workersが必要。
- MP4/MOV。一定・可変のフレーム間隔に対応。対応コーデックは端末のVideoDecoder.isConfigSupportedで確認し、未対応時に近傍時刻抽出で代用しない。
- MP4BoxでCTSとサンプルデータを読み、キーフレームからデコード順に投入。出力のPTSをコマ番号に照合。Bフレーム対応。
- 各コマのCTS（表示時刻）を読み取り、最初の表示コマからの時刻を保持。平均fpsは間隔の初期値・操作だけに使い、時刻表示、写真のラベル、座標データ、グラフは各コマの実際の記録時刻を使う。一定間隔では整数コマで抽出し、間隔が変わる動画では基準時刻に固定した等時間の候補から最も近い元コマを選ぶ。重複コマは取り除き、選択範囲の端点を追加しない。可変間隔・欠落・ギャップを平均間隔で埋めない。重複したCTSは明示的にエラーにする。
- 動画最大400 MiB、抽出最大240枚。画像長辺720/960/1280px。キャッシュ約80 MiBの予算に合わせて縮小。背景だけ追加抽出。
- MOV/MP4のQuickTime編集リスト（elst）の開始位置・空編集・再生速度を読み取り、元コマの記録時刻とブラウザーの再生時刻を分離。スロー再生でも表示するコマと解析時刻を一致させる。コマの記録時刻自体が再生用に書き換えられ、撮影時の時刻が失われたファイルでは、撮影時間を自動復元できない。時間間隔のfps表示から「撮影fpsで補正」を選べる。既知の一定fps・全コマが残っている場合だけ利用し、120/240fpsを推測しない。停止・逆再生・同じコマを繰り返す編集は明示的にエラーにする。
- カメラ撮影は端末のファイル入力/capture機能を利用。PC等ではファイル選択になる場合がある。WebMで録画された場合はMP4へ変換する必要あり。
- 写真はPNG、動画はH.264のMP4（シャッター音は任意）。共有APIのないブラウザーはダウンロードに切り替え。
- 動画はVideoEncoderの対応設定を検査し、最大60 fps・長辺960pxで出力。非対応なら最大30 fps・長辺720pxを検査。出力は元コマの実際の再生時刻を使い、スロー編集・可変間隔を含めて速度・再生時間を保つ。動く元映像は最後のストロボ抽出コマまで。続いて、同じ合成写真を約1秒保持する。
- 合成動画は元映像を毎コマ描画し、抽出時刻になった物体マスクだけを透明レイヤーに累積する。範囲の最後の物体像を余分に追加しない。
- 合成動画の設定キャッシュは範囲、基準、間隔、間引き、感度、時刻表示、ガイド線設定、対象指定・手動中心を含む。変更で古い動画を無効化。
- 動画出力はコマ数の進捗とキャンセルに対応。未対応端末では理由を表示し、写真機能を維持。MP4サイズ100 MiBまで。
- 一部のWebKitではworker内VideoDecoderやOffscreenCanvasが未対応の場合あり。Android ChromeとiPad Safariでの実機確認が必要。

## 開発

## 1.4で導入したコマごとの指定

- すべてのコマは未指定で始まり、自動追跡ではグリッドや時刻を追加しない。
- 「物体を選ぶ」で、表示中のコマの物体をタップする。そのコマだけの背景差分と領域検出を使い、タップに最も近い物体領域の中心を求める。領域への距離を画素単位で評価し、離れた大きな物体への吸着を避ける。検出できないときは、タップした位置をそのまま使う。
- 指定時に決定した座標を保存し、感度、背景、他のコマ、間引きの変更で検出し直さない。コマ番号ごとに独立した指定で、指定済みの点を別の点の編集によって移動させない。
- 「位置を調整」でタップ・ドラッグまたは矢印キー（Shiftで5px）により、そのコマの中心を修正する。
- 「打たない」は、そのコマにはグリッドと時刻を表示しない明示的な指定。「やり直す」は表示中のコマの指定だけを消去して未指定に戻す。次のタップで打たない指定を上書きできる。
- 中心座標は画像領域の面積中心またはユーザーの指定位置。物理的な重心と同一とは限らない。理想軌道への補正や他のコマへの補間は行わない。
- 間引いて隠れたコマの指定も保持し、元の間隔に戻すと復元する。同じ動画の範囲や間隔を変更して再抽出した際も共通コマの指定を保持。解像度が変わったときは保存時の座標系からスケール変換する。別の動画を読み込むと指定を初期化。
- 初めて点を指定するとグリッド表示をオンにする。縦線、横線、中心点のオン・オフ、色、0.5〜4pxの太さ、5〜100%の不透明度を変更可能。初期スタイルは白・1px・25%。同じ画素位置の線を重ねて濃くしない。設定は端末内に保存。
- グリッド修正は合成済みのベース画像を再利用して反映する。中心の指定・修正では再抽出も画像全体の再合成も行わない。感度・間引きを変更するとベース画像だけ作り直す。
- 写真と動画は同じ保存座標と描画処理を使用。動画では各抽出時刻に指定した線と時刻だけが累積する。未指定・打たないコマには表示しない。元動画の動きと物体像の累積は保ち、最後のストロボ抽出コマまで再生した後、完成写真を約1秒保持する。

追加検証: コマ編集のタップ・ドラッグ、現在コマだけのスキップ・消去、他のコマの不変性、未指定コマ、解像度変換、感度変更と間引き後の座標保持を検証。提供サンプルの実H.264をFFmpegでデコードし、12コマを個別にタップした場合の物体中心の補助検出を確認。Workerでは指定コマだけの線の累積、打たないコマの除外、最終保持画像と写真の一致、再抽出とキャンセルを確認。編集画面のイベント処理はDOMアダプターで検証し、実ブラウザーでの操作や端末固有のWebCodecsは未検証。この環境にはSitesが指定するcontrol-browserスキルがなく、公開前検証は自動テストと実動画・描画処理の確認で行う。


## 1.5 自動検出と座標表

- 手動選択を既定とし、「全コマを自動検出」で明示的に自動追跡を実行。最初に手動で指定したコマを起点に、前後の全抽出コマから同じ物体を探す。間引き中も抽出済みの全コマを処理する。新規動画読み込みで起点を初期化。起点を消す・打たないにする・範囲外にする場合は残った手動指定を使う。
- 背景差分の領域候補から、種の色・面積、連続した変位と速度予測を手がかりに、最大32経路を比較する。理想軌道への補正や未検出座標の補間は行わない。検出座標は領域の面積中心であり、物理的な重心とは限らない。見かけが大きく変わる物体、同じ見かけの複数物体、遮蔽などで誤検出・未検出は起こり得る。
- 手動の修正と「打たない」は固定し、再実行では自動の結果だけ更新する。未検出・競合候補による要確認は線と時刻から除外し、手動で修正可能。自動結果も保存し、感度や間引き変更で勝手に追跡し直さない。
- 抽出キャッシュを利用し、再デコードしない。コマごとに進捗を通知し、処理途中のキャンセルで未完成の指定を破棄する。背景差分・合成動画の物体マスクには影響しない。
- 完成写真に使用中のコマについて、時刻・x,y・指定状態を表で表示。座標は合成画像のピクセル、原点は左上、xは右向き、yは下向き。時刻は選択範囲の開始から、表示は小数第4位。未指定・未検出・要確認・打たないは座標を空欄にする。クリップボードはTSV、CSVはUTF-8 BOM付き。両形式に座標系の幅・高さを含める。揺らぎのある動画は画面上で時刻が概算と明示。
- 縦横線・検出ボタンの文言を変更。時間バーの範囲を淡い青にし、抽出点の青を見やすくした。ホームを指定の紹介文へ変更し、写真→見出し→説明のフェード・スライドを追加。操作ボタンは待たせず、動きを減らす端末設定に対応。

追加検証: 実サンプルの12コマを、途中の1コマだけの指定から前後に追跡。色や大きさの異なる物体、遠方の同色候補、消失、競合候補、手動座標とスキップの保持を確認。Workerでは全抽出コマのキャッシュ追跡、キャンセル、手動・自動座標の合成動画への反映を確認。座標の0値、空欄、4桁丸め、コピーとCSVの一致を確認。DOMアダプターで自動ボタンの起点・進捗・キャンセルを検証。実端末のブラウザー操作は未検証。


## 1.5.1 合成枚数の表示

時間間隔画面で、秒数の隣に合成する画像の枚数を同じ文字サイズで大きく表示。間隔、基準、開始・終了の変更に連動し、実際の抽出対象の数を示す。横画面でも枚数を省略しない。240枚を超える場合は枚数を表示したまま警告を出し、合成ボタンを無効にする。


## 1.5.2 ホームの登場演出

画像の表示準備と最初の描画を待ってから、写真のスライド＋フェード、見出し2行のマスクによる下からのスライド、説明3行の段階的フェードを開始。ホームに戻る場合とバックグラウンドから表示に戻る場合にも再生。操作ボタンは待たせない。画像待ちは最大1.1秒、最近の写真の復元待ちは最大0.3秒。JavaScriptが開始できない場合も2.4秒で通常表示に戻し、動きを減らす端末設定では演出を省略する。CSSとJSの参照に版番号を付け、古いキャッシュの影響を避ける。


## 1.5.3 タイトルと説明を2段階で表示

見出しの2行をひとまとまりで表示し、見出しの登場が終わった後に説明の3行をひとまとまりで表示。1行ごとの時間差を取り除いた。写真の演出・画像待ち・ホーム復帰時の再生・動きを減らす設定への対応は維持。


## 1.5.4 近くの物体を優先する自動検出

自動検出では全領域候補を保持し、画面全体の品質順で小さな対象を落とさない。手動指定した位置から始め、前の検出位置と速度から次の探索位置を求め、その周辺の最大6候補を比較。距離を色・面積や領域品質より強く評価する。探索範囲は物体サイズと実際の変位に応じて変わり、遠方の高品質な物体に飛ばないよう制限。手動修正の位置は背景差分の領域がない場合にも次のコマの探索基準として保持する。実際の検出領域の中心を記録し、座標の補間はしない。

検証: 提供サンプルの12コマを途中の手動指定から前後に追跡する既存検証に加え、近くの小さな対象と高品質の類似物体との競合、16位以下の対象を含む混雑画像、背景差分が出ない手動修正位置からの追跡を確認。CSS/JS/Workerの参照を更新し、旧処理のキャッシュを避ける。


## 1.6.0 画像を見ながら縦横線の角度を設定

- 「物体中心の縦横線」の設定で合成写真を表示。画像をなぞった方向に横軸を合わせ、その直角方向を縦軸にする。角度の初期値は0°。スライダー、0.1°単位の数値入力、0°に戻す操作にも対応。角度は画像上で時計回りが正、範囲は−90°〜90°。左右キーは1°、Shift併用は5°、Homeは0°。
- 線の表示を「縦横・縦だけ・横だけ・線なし」から選ぶ。中心点は独立してオン・オフ可能。色・太さ・不透明度も維持し、すべてを即時プレビューする。横画面では写真と設定を横に並べ、縦画面ではコンパクトに積む。「適用」で保存し、閉じると変更を破棄する。適用時に縦横線表示をオンにする。
- プレビューは注釈のない合成写真をキャッシュから取得。角度調整で動画の再抽出や全画像の合成を繰り返さない。中心未指定の場合は写真中央に角度確認用の線を表示するが、その位置を記録したり保存写真・動画に追加したりしない。
- 写真・動画・動画の最終保持画像で同じ回転した縦横線を描画。線は写真の端で切り、同じ軸上に重なる線はまとめる。物体の検出位置や座標表のx,yは変えない（座標表は従来どおり画像左上原点）。角度・片軸表示の変更で古い合成動画を無効にする。設定は端末内に保存。

追加検証: 斜めの線の直交性・中心通過・画像端での切断、縦線／横線／線なし、負角度・90°、回転後の重複線・未検出コマの除外、指でなぞる方向の反転、プレビュー設定の適用と破棄、数値・スライダー・キー操作の連動を確認。Workerでは注釈なし写真のキャッシュ利用、再デコードなしのプレビュー、片軸の回転線を動画に累積し、最終写真と一致することを検証。画面イベントはDOMアダプターによる検証で、実端末の描画・操作確認は未実施。


## 1.7.0 編集画面をコンパクトに整理

- 開始・終了・背景・基準に1コマずつ動かす±ボタンを追加。数値と点の操作は同じ更新処理を使い、動画を停止して指定したコマの時刻へ移動。始点と終点が逆転しないよう制限し、端では該当ボタンを無効にする。背景の自動設定と基準の範囲内への制限を維持。
- 時間バーを範囲カード内へ移し、次へを最下部に配置。時間間隔画面では、基準の下へ同じバーを移動して使用。バーを複製しないので設定と操作状態を共有。＋・−のズームでは開始・終了・背景（時間間隔画面では基準も）を表示内に保つ。ピンチ・パンは従来どおり、さらに細かい範囲の確認に使用できる。

## 1.11.0 sin（正弦波）のフィット

- 3つのグラフの「関数フィット」にsinを追加。モデルは `A sin(ω (u − u_ref) + φ) + C`、uは各グラフの横軸。振幅・角周波数・位相・中心位置を自動推定し、曲線と式だけを表示。sinの角度はラジアン。既存の多項式フィットと共通範囲・縮尺を維持。
- 各周波数でsin・cos・定数の最小二乗問題を解き、粗い周波数探索で得た上位の極小を細かく探索する。大きな時刻オフセットは横軸を中央に移して処理。未検出コマを除いた実際の座標を使い、等間隔に置き換えない。正弦波の描画点数も周期に応じて増やす。

- 方法の参考：[SciPyのfloating-mean Lomb–Scargle公式解説](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.lombscargle.html)。実装はブラウザーで動くJavaScriptで、SciPyの実行や追加通信は不要。

日本語版のブランド、ページタイトル、紹介文、検索・共有用メタデータの名称を「モーションストロボ」に統一。英語版はMotion Strobeを維持。サンプル選択ダイアログの灰色の背景をタップすると閉じ、下のホーム画面へ戻る。ダイアログ内の余白、動画カード、スクロール・ドラッグでは閉じない。既存の閉じるボタン・Escの操作を維持。

## 1.17.10 サンプルの列数

サンプルの選択画面を横幅に応じて2列・3列・4列へ切り替え。幅1200px以上は3列、1600px以上は4列。従来の760px幅の2列を基準に、カード幅を約353pxに保つようにダイアログ幅を1125px・1490pxへ拡張。スマホの2列・既存のサムネイル枠、黒背景・タイトルの配置を維持。CSSが指定する列数に合わせて独立した行へ再配置し、画面の回転やリサイズに追従。カードの順番とクリック操作、フォーカス、スクロール位置、灰色の背景で閉じる操作を維持。
