Motion Strobe 1.17.6 — ソース一式

【すぐに使う・Windows】
1. ZIPを全部展開します（ZIPの中から直接起動しないでください）。
2. Node.js 22以降が入っていれば「START-Windows.cmd」をダブルクリック。
   Node.jsがなく、Python 3がある場合はPythonで起動します。
3. 表示された http://localhost:5173 をChromeやEdgeで開きます。
   Node.jsでは5173番が使用中なら別の番号を表示します。
4. 「サンプルで試す」か、手持ちのMP4/MOVを選んでください。
終了するときは起動した画面で Ctrl+C。

【コマンドで使う・Windows / macOS / Linux】
Node.js 22以降を入れ、展開先のフォルダーで実行します。

    node serve.mjs

「npm start」でも同じように起動できます。
ビルド済みの dist が含まれているため、利用だけなら npm install は不要です。
インターネット接続なしでもローカルで利用できます。
index.html をダブルクリックする file:// では使わず、localhostで開いてください。

【ソースを変更してビルドする】
展開先のフォルダーで順に実行します。

    npm ci
    npm run build
    npm start

npm ci は最初にインターネット接続が必要です。依存関係はpackage-lock.jsonで固定しています。
src がアプリのソース、dist がそのビルド結果と画面・画像・サンプル動画です。
HTMLやCSSは dist/index.html と dist/style.css を編集します。
build はJavaScriptを更新します。HTML、CSS、画像、動画は消去しません。

【機能】
・開始／終了／背景／基準に1コマずつの±操作、動画時刻も連動
・各機能の「？」で説明、整数コマ分の時間間隔を選択
・ストロボ写真、元映像に物体像が累積するMP4動画の生成／保存／共有
・物体の位置を自動／手動で指定し、なしも選択、選んだ物体を起点にした全抽出コマの自動検出
・コマごとの「なし」、物体中心の縦横線と時刻表示
・合成写真をなぞって縦横線の角度を設定、縦だけ／横だけの表示
・時刻とx,yの座標表、コピー、CSV保存
・キャンセル、進捗表示、間引き、最近の写真を端末内に保存

【iPhone／iPadなどから利用する】
dist フォルダーをHTTPSの静的Webサーバーへ置いて開きます。
アプリ用のAPIキーや専用バックエンドは不要です。
単純なLANの http://PCのIPアドレス ではWebCodecsが使えない場合があります。
対応はブラウザーのWebCodecsなどの機能で決まり、未対応時は画面に理由を表示します。
実端末の動作確認は別途必要です。動画はサーバーにアップロードしません。

【テスト】
    npm test

時刻表示の初期値は小数第2位です。設定で0〜6桁を選べます。
FFmpegが入っていれば実動画のデコードも検証します。
実ブラウザーの描画・WebCodecsは実機で確認してください。
README.md に実装の説明、制限、検証内容が載っています。
SOURCE_VERSION.txt に元の公開ソースのコミットを記録しています。
